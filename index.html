음정은 음과 음 사이의 거리입니다.
음정을 구할 때는 순서를 지켜서 구하는 것이 좋습니다.

01

먼저, 음정의 도수를 구해요.

‘도’와 ‘도’처럼 같은 위치에 있는 음은 1도라고 합니다.

출발하는 음도 포함해서 세어요
도①→레②→미③

따라서 ‘도–미’는 3도입니다.

카드를 누르면 두 음이 피아노 소리로 동시에 울립니다. 마지막 ‘도’는 한 옥타브 위의 도입니다.

피아노: Salamander Grand Piano · Alexander Holm · 샘플 출처

02

도수는 두 그룹으로 나눠요.

완전음정 그룹과 장음정 그룹으로 구분합니다.

완전음정 그룹

03

도에서 시작하는 기본 음정.

이 수업에서는 도에서 시작해 임시표 없는 도·레·미·파·솔·라·시·높은 도로 향하는 음정을 기본 음정으로 삼습니다.

여기서 세는 ‘반음’은 무엇일까요?

두 음 사이를 음이름 순서로 따라가며 미–파와 시–도 구간이 몇 개 포함되는지 셉니다. 두 음 사이의 전체 거리를 반음 단위로 센 숫자와는 다릅니다.

도–파에는 미–파가 들어가고, 도–높은 도에는 미–파와 시–도가 모두 들어갑니다.

04

반음과 온음, 건반에서 확인해요.

바로 이웃한 두 건반 사이의 거리는 반음입니다. 중간에 건반 하나가 있으면 온음입니다.

미–파

사이에 다른 건반이 없어요. 바로 이웃한 두 건반이므로 반음입니다.

시–높은 도

미–파와 마찬가지로 바로 이웃한 두 건반입니다.

도–레

사이에 검은 건반 하나가 있어요. 온음입니다.

B♭–C

사이에 B(시) 건반 하나가 있어요. 중간 건반이 흰색이어도 온음입니다.

미–파 사이에는 검은 건반이 없고, 도–레 사이에는 검은 건반 하나가 있습니다. 다만 검은 건반의 유무만으로 판단하지는 않아요. B♭–C처럼 중간 건반이 흰색이어도 온음입니다.

05

같은 3도인데, 간격이 달라요.

기본 음정인 도–미와 레–파를 비교해 보세요.

도–미
3도미–파·시–도 0개

장3도

도 → 레 → 미에는 미–파·시–도 구간이 없습니다. 기본 음정인 장3도입니다.

레–파
3도미–파·시–도 1개

단3도

레 → 미 → 파에는 미–파가 1개 들어갑니다. 도–미보다 간격이 반음 좁습니다.

두 음 모두 3도이지만 레–파는 기본 음정인 도–미보다 간격이 좁아집니다. 그래서 장3도에서 왼쪽으로 한 단계 이동해 단3도가 됩니다.

← 간격 감소간격 증가 →

같은 도수에서 간격이 반음 좁아지면 왼쪽으로, 반음 넓어지면 오른쪽으로 이동합니다.

06

반음 구간이 늘면, 간격은 좁아져요.

임시표 없는 음끼리 같은 도수를 비교할 때, 미–파·시–도 구간이 늘면 간격이 감소하고, 줄면 간격이 증가합니다.

도–파
4도미–파·시–도 1개

완전4도

도 → 레 → 미 → 파: 미–파가 1개 들어갑니다. 기본 음정인 완전4도입니다.

파–시
4도미–파·시–도 0개

증4도

파 → 솔 → 라 → 시: 미–파·시–도 구간이 없습니다. 도–파보다 간격이 반음 넓습니다.

미–파·시–도 구간: 1개 → 0개
두 음 사이의 간격: 반음 증가

도–파와 파–시는 모두 4도입니다. 반음 구간이 하나 줄어 간격이 넓어졌으므로, 완전4도에서 오른쪽으로 이동해 증4도가 됩니다.

08

변화표는 마지막에 적용해요.

먼저 변화표가 없는 음정을 구합니다. 그다음 ♯이나 ♭을 적용해 간격이 넓어졌는지 좁아졌는지 확인합니다.

도수는 그대로, 두 음 사이의 간격만 확인하세요.

높은 음이 움직이는지, 낮은 음이 움직이는지에 따라 결과가 달라집니다.

변화표가 붙는 음♯ · 반음 올림♭ · 반음 내림
위의 음간격 증가 →← 간격 감소
아래의 음← 간격 감소간격 증가 →

위의 음이 변할 때

C–E = 장3도
C–E♯ = 증3도 · 반음 넓어짐
C–E♭ = 단3도 · 반음 좁아짐

아래의 음이 변할 때

C–E = 장3도
C♯–E = 단3도 · 반음 좁아짐
C♭–E = 증3도 · 반음 넓어짐

두 음에 같은 변화표가 붙으면 간격은 같아요.

C♯–E♯, C♭–E♭은 C–E와 같은 장3도입니다. 두 음이 같은 방향으로 같은 만큼 움직이기 때문입니다.

다만 C♯–E♭처럼 서로 다른 변화표가 붙으면 각각의 변화를 적용해야 합니다. 이 경우 간격이 반음씩 두 번 좁아져 감3도가 됩니다.

더블샵 · x

반음 두 번 올림

C–Ex: 장3도에서 두 반음 넓어져 겹증3도입니다.

더블플랫 · ♭♭

반음 두 번 내림

C–E♭♭: 장3도 → 단3도 → 감3도로 변합니다.

Ex은 F♯과 같은 높이지만, C–Ex의 도수는 음이름 C–E를 따라 3도입니다. 변화표는 도수를 바꾸지 않습니다.

FIRST LESSON · MAJOR TRIAD

메이저 코드 첫걸음

같은 간격으로, 모든 메이저 코드를 연주합니다.

처음에는 복잡한 음정 이름보다 소리와 건반 사이의 거리에 익숙해져 봅니다. 코드 이름을 소리 내어 말하면서 C에서 위의 C까지 올라갔다가 내려옵니다.
01

건반 사이의 거리부터 알아봅니다.

반음 · Half Step

흰건반과 검은건반을 모두 포함하여 바로 옆 건반으로 한 칸 이동하는 거리입니다. 미–파, 시–도도 반음입니다.

온음 · Whole Step

반음 두 번의 거리입니다. 두 음 사이에 건반이 하나 있습니다. 도–레, 시♭–도도 온음입니다.

02

메이저의 간격을 유지합니다.

오른손으로 도·미·솔을 함께 눌러 C 메이저를 연주합니다. 낮은 음부터 반음 4칸 + 반음 3칸의 간격입니다. 출발 건반을 0으로 두고 이동한 칸 수를 셉니다.

도 C — 반음 4칸 — 미 E — 반음 3칸 — 솔 G

세 음을 모두 반음씩 올리면 C♯ 메이저가 됩니다. 검은건반 배치는 달라져도 이 간격은 그대로입니다. 왼손은 코드 이름에 해당하는 근음을 연주합니다.

03

올라갈 때는 ♯으로 말하며 연주합니다.

C → C♯ → D → D♯ → E → F → F♯ → G → G♯ → A → A♯ → B → C

“씨 메이저, 씨 샵 메이저, 디 메이저…”라고 말하며 한 코드씩 연주합니다. E–F와 B–C 사이에는 검은건반이 없지만 반음씩 올라갑니다.

04

내려갈 때는 ♭으로 말하며 연주합니다.

C → B → B♭ → A → A♭ → G → G♭ → F → E → E♭ → D → D♭ → C

“씨 메이저, 비 메이저, 비 플랫 메이저…”라고 말하며 내려옵니다. C♯과 D♭처럼 이름은 달라도 피아노에서 같은 건반을 누르는 코드가 있습니다.

천천히 이름 말하기 → 오른손 코드 → 왼손 근음과 함께 연주하기.

HARMONY · CHORD STRUCTURE

코드

Triad Chord & 7th Chord · 3화음과 7화음

16개의 기본 코드, 하나의 근음으로 비교하기.

코드(Chord)는 여러 음을 함께 묶은 화음이다. 이 장에서는 C를 근음으로 한 16개 기본 코드를 통해 구성음과 기호의 관계를 정리한다.

01 · 근음

C는 기준이 되는 근음이다. 코드의 종류가 바뀌어도 이 장의 근음은 C로 유지된다.

02 · 도수 공식

HARMONY · DIATONIC CHORDS

다이아토닉(Diatonic)

한 스케일의 음으로 만드는 코드.

THE FOUNDATION OF HARMONY

다이아토닉(Diatonic)이란?

한 곡의 조성을 이해하려면 먼저 그 조의 기본 음계, 즉 스케일(Scale)을 살펴보아야 합니다. 다이아토닉(Diatonic)은 이처럼 기준이 되는 온음계에 속하는 음과 화음을 가리킵니다. 이 수업에서는 장음계(Major Scale)를 기준으로 코드를 만드는 방법을 다뤄보겠습니다.

C 장음계(C Major Scale)의 음은 도·레·미·파·솔·라·시입니다. 이 일곱 음 안에서만 음을 골라 3도씩 쌓으면 다이아토닉 코드(Diatonic Chord)가 만들어집니다. 같은 음계에서 만들어졌기 때문에 곡의 조성을 이루는 기본 화음으로 활용할 수 있습니다.

다이아토닉을 구분하는 기준은 흰건반인지 검은건반인지가 아닙니다. 선택한 스케일에 포함되는 음인가가 기준입니다. D 장음계(D Major Scale)에서는 파♯(F♯)과 도♯(C♯)도 기본 음계에 포함됩니다.

01
SCALE → CHORD

스케일에서 3도씩 쌓기

C 장음계(C Major Scale)는 C · D · E · F · G · A · B입니다. 각 음을 근음으로 정하고, 스케일에서 한 음씩 건너뛰며 쌓아보겠습니다. 이때 3도는 항상 장3도가 아니라 장3도 또는 단3도가 됩니다.

C에서 시작

C → E → G : C 메이저 3화음(C Major Triad)

C → E → G → B : CM7

D와 F를 건너뛰어 3화음을 만들고, A를 건너뛰어 7음을 더합니다.

D에서 시작

D → F → A : D 마이너 3화음(D Minor Triad)

D → F → A → C : Dm7

같은 C Major Scale의 음을 사용하므로 F♯이 아닌 F를 쌓아보겠습니다. 시작음을 D로 바꿔도 D Major Scale로 바꾸는 것은 아닙니다.

02
DIATONIC TRIAD

다이아토닉 3화음(Diatonic Triad)

스케일의 각 음 위에 3도씩 세 음을 쌓아보겠습니다. 아래 악보는 모두 기본위치로 표기되어 있습니다.

I · ii · iii · IV · V · vi · vii°

메이저 · 마이너 · 마이너 · 메이저 · 메이저 · 마이너 · 디미니시드

대문자는 메이저, 소문자는 마이너를 나타내며 °는 감3화음을 나타냅니다.

03
DIATONIC 7TH CHORD

다이아토닉 7화음(Diatonic 7th Chord)

각 3화음(Triad) 위에 스케일의 음을 하나 더, 3도 간격으로 쌓아보겠습니다. 근음에서 7도 위의 음까지 포함하는 네 음의 화음이 됩니다.

도수Triad더하는 음정 · 근음 기준7th Chord

iiDm단7도 · CDm7
iiiEm단7도 · DEm7
IVF장7도 · EFM7
VG단7도 · FG7

어떤 장조(Major Key)에서도 이 코드 성질의 순서는 같습니다. 실제 구성음은 각 조의 조표와 스케일에 맞춰 바뀝니다.

Bdim에 A를 더하면 Bm7(b5)이 됩니다. 감7화음 Bdim7을 만들려면 A♭이 필요하지만, A♭은 C Major Scale에 포함되지 않습니다.

04
C MAJOR → D MAJOR

D Major에서도 같은 원리로 만들어봅니다.

D 장음계의 조표는 F♯과 C♯입니다. 이 두 음을 포함한 스케일에서 한 음씩 건너뛰어 3도씩 쌓으면 D Major의 다이아토닉 코드가 만들어집니다.

D Major Scale · D 장음계

Diatonic Triad · 다이아토닉 3화음

조가 바뀌어도 코드 성질의 순서는 같습니다.

C Major의 ii는 Dm, D Major의 ii는 Em입니다. 각 스케일의 두 번째 음부터 3도씩 쌓았기 때문에 둘 다 마이너 3화음이 됩니다.

C♯dim에 B를 더하면 C♯m7(b5)입니다. C♯dim7에 필요한 B♭은 D Major Scale에 포함되지 않습니다.

HARMONY · MELODY IN MOTION

비화성음(Non-Chord Tone)

화음 사이를 연결하고, 선율에 표정을 더하는 음.

CHORD TONE → NON-CHORD TONE → RESOLUTION

화음 밖의 음은 어떻게 음악이 될까요?

현재 화음을 이루는 음을 화성음(Chord Tone), 그 화음의 구성음에 속하지 않는 음을 비화성음(Non-Chord Tone)이라고 합니다. C 코드의 화성음은 C·E·G입니다. C와 E 사이에 D를 넣으면, D가 두 화성음을 자연스럽게 연결할 수 있습니다.

비화성음은 잘못된 음이라는 뜻이 아닙니다. 어떤 화음 위에 놓이는지, 앞뒤 음과 어떻게 연결되는지에 따라 선율의 흐름과 긴장을 만들어줍니다.

01 · 화음 확인

그 순간의 코드와 구성음을 먼저 살펴보아야 합니다.

02 · 움직임 확인

순차진행인지 도약인지, 같은 음을 유지하는지 확인합니다.

03 · 위치와 해결

강박·약박과 화음의 변화, 해결되는 음을 함께 살펴봅니다.

9가지 유형을 실제 악보와 함께 살펴보겠습니다. 동그라미로 표시한 음이 비화성음이며, 아래 약어로 종류를 확인할 수 있습니다. 악보의 코드 기호와 음가를 그대로 유지하고, 뒤의 빈 마디는 생략했습니다. 원본에 박자표는 없으며 각 예시는 음가 합계가 4분음표 4개인 한 마디로 구성되어 있습니다.

01

경과음

Passing Tone · P.T.

두 화성음 사이를 같은 방향의 순차진행으로 연결합니다.

C → D → E

C 코드의 화성음 C와 E 사이를 D가 연결합니다. 도→레→미로 올라가며, 가운데 레(D)가 경과음입니다.

점4분음표 C → 8분음표 D → 2분음표 E. 짧게 지나가는 D의 역할을 확인해 보세요.
02

보조음

Neighbor Tone · N.T.

화성음에서 이웃한 음으로 움직인 뒤 원래 화성음으로 돌아옵니다.

E → F → E

C 코드의 E에서 위쪽 이웃음 F를 거쳐 E로 돌아옵니다. 가운데 파(F)가 위 보조음입니다.

미→파→미는 위 보조음의 예시입니다. 아래쪽 이웃음을 거쳐 돌아오는 아래 보조음도 있습니다.
03

전타음

Appoggiatura · App.

강한 위치의 비화성음이 순차 해결되며 화성음의 도착을 늦춥니다.

D → C

C 코드 위에서 레(D)가 먼저 울리고, 도(C)로 한 음 내려가 해결합니다. 강박에 놓인 D가 긴장을 만들고, 화성음 C로 2도 하행하여 해결합니다.

첫 음 D는 4분음표, 해결음 C는 점2분음표입니다. 강한 위치의 긴장과 뒤따르는 해결에 주목해 보세요.
04

이탈음

Escape Tone · Esc.

2도 상행하거나 하행한 뒤, 반대 방향으로 3도 이상 도약하여 화성음으로 해결합니다.

D → E → C

G 코드의 레(D)에서 미(E)로 2도 올라간 뒤, 도(C)로 3도 내려갑니다. E는 G 코드의 비화성음이며, C 코드로 바뀌는 순간 C에 해결합니다.

이 악보는 2도 상행 후 3도 하행하는 예시입니다. 해결 도약은 3도에 한정되지 않으며, 반대 방향의 화성음으로 연결되는지 확인해야 합니다.
05

겹보조음

Changing Tone · Double Neighbor · C.T.

위·아래 보조음을 모두 거쳐 출발했던 화성음으로 돌아옵니다.

C → D → B → C

C 코드의 도(C)를 중심으로 레(D)와 시(B)를 연이어 거친 뒤 C로 돌아옵니다. 가운데 D와 B가 한 쌍의 보조음입니다.

이 장에서는 Changing Tone이라는 명칭을 사용합니다. Double Neighbor 또는 Double Neighboring Tone으로도 설명되는 유형입니다.
06

캄비아타

Cambiata · Camb.

3도 도약한 뒤 반대 방향으로 2도 이동하여 화성음으로 해결합니다.

D → B → C

Dm 코드의 레(D)에서 시(B)로 3도 내려간 뒤, C 코드의 도(C)로 2도 올라갑니다. B는 Dm 코드의 비화성음입니다.

캄비아타(Cambiata)는 이 교재에서 Camb.로 표기합니다. 이 장은 사용 교재의 캄비아타 정의를 따릅니다. 도약 진입형 불완전 보조음(Incomplete Neighbor)과 연결하여 이해할 수 있습니다.
07

선행음

Anticipation · Ant.

다음 화음의 구성음이 화음 변화보다 먼저 등장합니다.

D → C | C

G 코드가 유지되는 동안 도(C)가 먼저 나타납니다. 붙임줄로 이어지는 C는 화음이 C로 바뀌면 화성음이 됩니다.

첫 번째 C는 G 코드 위의 비화성음이고, 두 번째 C는 C 코드의 화성음입니다. 붙임줄이 있어도 이 경우는 선행음입니다.
08

계류음

Suspension · Sus.

이전 화음의 음을 유지한 뒤 새 화음의 화성음으로 한 음 아래로 해결합니다.

D | D → C

G 코드의 화성음 레(D)를 C 코드까지 붙임줄로 유지한 뒤 도(C)로 내려갑니다. 유지된 D가 C 코드의 비화성음이 됩니다.

C를 베이스로 두면 D→C는 9–8 하행 계류입니다. 제공 악보에는 베이스 성부가 없으므로 이 숫자는 C 베이스를 전제로 한 설명입니다.
09

지속음

Pedal Point · Ped.

한 음을 유지하는 동안 화음이 바뀌어 화성음과 비화성음의 역할을 오갑니다.

C 유지 / F → G → C

도(C)를 붙임줄로 유지하는 동안 화음은 F→G→C로 바뀝니다. C는 F의 화성음, G의 비화성음, C의 화성음이 됩니다.

이 예시에서는 높은음자리표 성부에 C가 유지됩니다. 지속음은 저음뿐 아니라 위 성부에도 나타날 수 있습니다.

같은 음도 문맥에 따라 역할이 달라집니다.

C 코드 위에서 짧게 지나가는 D는 경과음이 될 수 있습니다. 반면 Cadd9의 구성음으로 지속되는 D는 그 화음의 일부로 해석할 수 있습니다. 음이름만 보고 비화성음의 종류를 정하지 않고, 화음과 선율의 흐름을 함께 확인해야 합니다.

재즈의 텐션과 전통 화성학의 비화성음은 분석 관점이 다를 수 있습니다. 이 장에서는 명시한 기본 화음을 기준으로 준비·진행·해결을 살펴보겠습니다.
