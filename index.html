02 / TEMPO

장면에 딱 맞는 템포.

원하는 시간과 마디를 입력하면 일정한 템포를 계산합니다.

♩TIME → TEMPO
목표 시간
:

1마디 1박은 0:00입니다. 목표 위치는 해당 박이 시작되는 순간입니다. 6/8·9/8은 8분음표 한 개를 1박으로 선택하며, 결과 BPM은 4분음표(♩) 기준입니다.

♩ = BPM

DAW에 반올림해서 입력할 때

입력 BPM실제 도착 시간목표와 차이

+는 목표보다 늦게, −는 일찍 도착합니다. 템포·박자가 일정하고 못갖춘마디가 없는 경우를 기준으로 계산합니다.
